CopyJSONReference
=================

Thank you for installing CopyJSONReference!

Right-click any key or value in a JSON file and choose
"Copy JSON Reference" (it appears near the regular Copy item).

You can also run "Copy JSON Reference" from the Command Palette.

The path will be copied to the clipboard in the form:

    body.data.values.contact

No shortcut is enabled by default. To add one, open
Preferences → Key Bindings and copy the example from
Default.sublime-keymap (Ctrl+Alt+J, JSON files only).

Settings are under Preferences → Package Settings →
CopyJSONReference → Settings, or via
"Preferences: CopyJSONReference Settings" in the Command Palette.

Enjoy!
